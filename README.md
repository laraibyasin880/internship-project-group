# TradesDash

A web app for UK tradespeople (plumbers, electricians, gas engineers) to manage quotes, jobs, invoices, WhatsApp conversations and safety certificates.
WhatsApp, payments and AI are simulated.

## Group 2: Customer, Messaging and Compliance

This branch (`watsapp`) holds the WhatsApp Hub screens built by G2-S1:

- Inbox (`/inbox`)
- Quote Thread (`/inbox/quotes/:id`)
- Invoice Thread (`/inbox/invoices/:id`)

## Tech stack

React, Vite, Tailwind CSS v4, React Router, lucide-react.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:5173/inbox
